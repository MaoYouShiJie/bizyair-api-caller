BizyAir API 工具 - 测试和打包指令
====================================

【首次使用】
1. npm install            # 安装依赖
2. npm run build          # 构建前端
3. npm run electron:prod  # 测试运行
4. npm run dist           # 打包 exe（输出到 release/）

【日常开发】
改完代码后：
  npm run build           # 重新构建
  npm run electron:prod   # 测试效果
  npm run dist            # 打包发布

【注意事项】
- electron:prod 按 F12 打开开发者工具
- 打包后的 exe 在 release/ 目录
- 用户数据保存在 exe 同级目录
